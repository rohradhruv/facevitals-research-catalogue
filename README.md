# FaceVitals Research Catalogue

A static, searchable student research catalogue for IEEE SP Cup 2027 FaceVitals.

- Open `index.html` to use the catalogue.
- Includes 208 source-linked entries and a historical SP Cup review.
- No login, database, external runtime or paid hosting is required by these files.
- This is an independent research aid, not an official IEEE website or a medical device.
- Original papers, software, data and trademarks retain their respective rights. Linked code/data require their own license review.
- Source availability does not establish reproduced accuracy or clinical validation.

## Publish with GitHub Pages

Create a public repository, upload these files preserving the `Historical_SP_Cup` folder, then open Settings → Pages. Choose Deploy from a branch, select `main` and `/ (root)`, and save. Wait for GitHub's deployment to finish, then use the site URL shown there.

Only this prepared folder should be published. The private working directory contains additional materials that are not part of this site.
